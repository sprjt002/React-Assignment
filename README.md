# Strudel Demo

This project was bootstrapped with [Create React App](https://github.com/facebook/create-react-app).

## Play and Pause

this controls when the music plays and stops

## Json

the save json saves the current cpm and volume settings locally, then when load json is pressed the most recently saved json will load and the volume and cpm will change.

## setCPM

this changes the tempo of the music

## Volume

the volume slider adjusts the volume of the music
